The Alters Save Editor
======================

This is a browser-based tool - there is nothing to install.

Open:  https://iteratrix.github.io/alters-save/

1. Close The Alters (and consider pausing Steam Cloud sync for it).
2. Drop your newest save file onto the page. Save locations:

   Windows (Steam):
     %LOCALAPPDATA%\11bitstudios\TheAlters\Steam\Saved\SaveGames\<SteamID>\

   Steam Deck / Linux (Proton):
     ~/.steam/steam/steamapps/compatdata/1601570/pfx/drive_c/users/steamuser/
       AppData/Local/11bitstudios/TheAlters/Steam/Saved/SaveGames/<SteamID>/

   Edit the newest *-ACT*-day-*.sav file.

3. Click "Download backup" first. Always.
4. Edit resources, items, day/time, alter moods, research, quest deadlines.
5. Save. On Chrome/Edge it writes straight back to the file; on other
   browsers it downloads the edited file - move it back into the save
   folder, replacing the original (that's what the backup is for).

Everything runs locally in your browser. Your save is never uploaded
anywhere.
