Edit the newest *-ACT*-day-*.sav file. Close the game first, and consider pausing Steam Cloud sync for The Alters so it doesn't restore the old file.

Time

The load menu labels saves by day, so an edited save keeps its old label until the game re-saves. Rewinding days can desynchronize story pacing - small nudges are safer than large jumps.
